# Laravel Boost

Use this skill for Laravel projects or tasks that explicitly need Laravel framework conventions.

## Workflow

1. Confirm the project is Laravel before applying Laravel-specific guidance.
2. Prefer framework documentation and project conventions over generic PHP advice.
3. Use Laravel Boost tools when available for routes, config, migrations, models, and artisan discovery.
4. Keep Laravel-specific rules out of non-Laravel baseline instructions.
